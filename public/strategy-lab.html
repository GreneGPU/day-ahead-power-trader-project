01 Define the signal

Upload required: outages in MW. Missing data is never assumed to be zero.

Features you can use

Power forecasts
wind, solar, demand (or load_fc) in MW.
Price forecasts
forecast, baseline in DKK/MWh.
Weather history
temperature_lag_*, humidity_lag_*, weather_wind_speed_lag_*.
Gas price history
gas_price_lag_*, plus the daily change and seven-day mean listed below.
System balance history
system_balance_MWh_known_lag96 in MWh.

Replace * with 96, 192 or 672 for 1, 2 or 7 days earlier. Historical features keep their source units and existing lags.

Saved model features (16) · click to insert

Names are exact. Values keep their source units and existing lags; they are not normalized or shifted again.

Formula syntax

Use + − * / and parentheses. Functions: abs(x), sign(x), min(x,y), max(x,y), avg(x,y), clamp(x,low,high). Thresholds use the formula’s output units; inputs are not normalized.

Upload optional data

HourUTC,outages; optionally add demand,wind,solar to replace the saved forecasts. Use forecasts or outage information known before each decision.

Using saved wind, solar, demand and lagged model features. Only outages need an upload.

Columns: HourUTC,Signal. Use timestamps with a timezone, e.g. Z for UTC. Include every interval in your test period.
